Описание (авторское): Приложение запись экрана + кейлог + инфа о устройстве отправка по вебхуку.

⚙️ Техническая реализация:

Сбор информации: Чтение системных переменных (OS, hostname, username) через os / platform (Python) или WinAPI.

Запись экрана: Использование библиотек захвата экрана (например, mss или pyautogui) с сохранением кадров в буфер или временный файл.

Кейлоггер: Перехват событий клавиатуры на уровне ОС (через библиотеку pynput или keyboard), логирование нажатий в скрытый файл.

 Собранные данные упаковываются в архив и отправляются POST-запросом на Discord Webhook/ Временные облачные сервисы / анонимные почты (адекватно реализован только Discord, на осталное жалуется система + антивирусы). Для обхода ограничений по размеру файла отправка может производиться частями (chunked upload).
