## 📂 Структура проекта (Ветки)
В репозитории 4 независимые ветки:
1. **app** — Приложение (запись экрана, кейлоггер, сбор инфы).
2. **cookie-exporter** — VPN-ловушка (кража куки + ТГ сессий).
3. **cookie-exporter2** — Легальный дампер/импортер сессий.
4. **xscrape-main** — Скилл для агента, обход антивируса + создание загрузчика и в дальнейшем возможное внедрение вредоносного ПО через него.
*Расширения под браузеры на хромиум движках. Тестировались в хром/яндекс
*Переключайтесь между ветками в выпадающем списке сверху.*
