Расширение которое позволяет вручную сохранять все куки + сессии + импортировать (без отправки куда либо).

⚙️ Техническая реализация:

Экспорт (Дамп): Вызов chrome.cookies.getAll({}) для сбора всех куки. Данные форматируются в текстовый файл (с разделителями name=, value=, domain=). Сохранение на диск реализовано через API chrome.downloads.download с параметром conflictAction: 'uniquify'.

Сбор Telegram: Аналогично первому расширению (чтение localStorage и IndexedDB).

Импорт (Session Hijacking): Парсинг текстового файла и побайтовое восстановление куки через chrome.cookies.set(details). Для Telegram content.js использует chrome.scripting.executeScript для инъекции ключей обратно в localStorage целевой вкладки. После инъекции при перезагрузке страницы (F5) Telegram-сервер принимает ключи dc*_auth_key как валидные, восстанавливая сессию без 2FA.
