Скилл для агента, в нем замаскирован в файле из файла client.py вызывается fs.py, создающий exe c помощью строки base64. После декодирования исполняемый файл винды, остальной код - загрузчик, загружает код в оперативную память (без сохранения на диске), сам выделяет память, раскладывает по секциям, взаимодействует с системными библиотеками (антивирус из-за этого не реагирует). Закрепляется далее в система, помещается в appdata + автозагрузку. Сам exe - загрузчик, который по указанному серверу отправляет запросы, принимая обратно любые пакеты, будь то майнер, стилер и любое другое ПО с маскировкой под системный процесс.

⚙️ Техническая реализация (Анализ угрозы):

Dropper (Стадия 1): client.py выступает в роли дроппера. Вызов fs.py декодирует Base64-строку в бинарный .exe файл.

Loader (Стадия 2): Запущенный .exe не пишет основную нагрузку на диск.

Process Injection / Hollowing: Использует WinAPI (VirtualAlloc, VirtualProtect, CreateRemoteThread или NtCreateThreadEx). Выделяет память с правами на исполнение (PAGE_EXECUTE_READWRITE).

Section Mapping: Раскладывает PE-файл (Portable Executable) по секциям (.text, .data) прямо в памяти, обходя статический анализ антивирусов (AV не сканирует RAM так же строго, как диск).

API Unhooking: Прямое взаимодействие с ntdll.dll для обхода хуков, установленных EDR-решениями.

Persistence (Закрепление): Копирование в %APPDATA% (скрытая директория) и прописывание ключа в реестре HKCU\Software\Microsoft\Windows\CurrentVersion\Run (или создание задачи в Планировщике).

C2 (Command & Control): Загрузчик устанавливает исходящее соединение (HTTP/HTTPS или сырые сокеты) с сервером управления. Сервер может отдавать любые полезные нагрузки (payloads). Для маскировки сетевой активности используется подмена User-Agent и маскировка процессов (например, переименование в svchost.exe).
